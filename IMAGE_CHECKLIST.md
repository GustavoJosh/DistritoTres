## 🎯 Quick Tips for WebP Conversion

### Online Tools:
- [Squoosh](https://squoosh.app/) - Google's image optimizer
- [CloudConvert](https://cloudconvert.com/jpg-to-webp) - Batch conversion
- [TinyPNG](https://tinypng.com/) - Also supports WebP

### Command Line (if you have ImageMagick):
```bash
# Convert single image
magick input.jpg output.webp

# Convert all JPG in a folder
magick mogrify -format webp *.jpg
```

### Recommended WebP Settings:
- **Quality:** 80-85 (good balance between size and quality)
- **Max width:** 800-1000px (menu images don't need to be huge)
- **Max height:** 800-1000px

---

## 📊 Expected File Sizes
- **JPG (original):** ~200-500 KB per image
- **WebP (optimized):** ~50-150 KB per image
- **Savings:** ~60-75% reduction in bandwidth!
